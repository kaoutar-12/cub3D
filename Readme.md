# Pre-Push Checklist

Before pushing any changes to the repository, ensure the following steps are taken:

## Code Quality and Safety

1. **Memory Management:**
   - Remove all memory leaks to ensure proper execution in case of closing the window or pressing the escape key.

2. **Norminette:**
   - Run the Norminette tool to ensure adherence to coding standards and guidelines. Make necessary adjustments to comply with the norm.

## Code Understanding

3. **Execution Flow:**
   - Gain a comprehensive understanding of the first part of the execution process. Document any intricate details or dependencies for future reference.

## General Guidelines

- Always review and test your changes thoroughly before pushing to maintain code integrity.

*Note: Ensure that your code is well-documented and follows best practices for readability and maintainability.*
